# 组件测试指南

本文档说明如何测试项目中的所有组件以及后端 Service 逻辑。

---

## 🚀 快速开始

### 1. 启动开发服务器

```bash
npm run dev
```

访问：http://localhost:3000

---

## 🤖 自动化单元测试 (v0.4.0)

本项目使用 **Jest** 对核心逻辑进行单元测试。

### 1. 运行测试

```bash
# 运行所有测试
npm test

# 检查测试覆盖率
npm run build # 构建过程会自动执行 lint 和类型检查
```

### 2. 测试覆盖范围

- **BaseService**: 测试重试机制、状态流转和通知触发逻辑。
- **SupabaseService / LeanCloudService / GladosService**: 测试数据库操作流程。
- **heatmap-utils (v0.8.0)**: 测试热力图聚合逻辑，包括服务级最终一致性、跨时区处理。
- **heatmap-calendar (v0.8.2)**: 测试日历计算函数，包括日期生成、闰年处理、月份标签。
- **组件测试 (v0.8.2)**: TaskCard 和 Heatmap 组件的渲染、交互测试。
- **Utils**: 测试通用工具函数。

## 🧪 组件测试清单

### ✅ TaskCard（任务卡片）

**位置**：主页面的三个卡片

**测试方法**：

1. 访问 http://localhost:3000
2. 观察三个任务卡片（Supabase、LeanCloud 和 GLaDOS）
3. 点击 "Run Task" 按钮
4. 观察状态变化：
   - Loading 状态（按钮显示 "Running..."）
   - Success 状态（绿色提示）
   - Error 状态（红色提示）

**测试点**：

- ✅ 卡片布局和样式
- ✅ 按钮点击响应
- ✅ 加载状态显示
- ✅ 成功/失败消息（**注意**：消息不应自动消失）
- ✅ 统计数字更新

---

### ✅ Heatmap（签到热力图）(v0.8.0)

**位置**：主页面底部

**测试方法**：

1. 访问 http://localhost:3000
2. 滚动到页面底部，观察热力图
3. 将鼠标悬浮在不同的格子上
4. 观察 Tooltip 显示

**测试点**：

- ✅ 热力图正确渲染 (GitHub 风格)
- ✅ 绿色格子表示全部成功
- ✅ 红色格子表示有失败
- ✅ 灰色格子表示无数据
- ✅ Tooltip 显示日期和状态
- ✅ 失败时 Tooltip 显示失败的服务名称
- ✅ 月份和星期标签正确显示

### ✅ RollingNumber（滚动数字动画）

**位置**：TaskCard 中的统计数字

**测试方法**：

1. 点击 "Run Task" 按钮

**测试点**：

- ✅ 数字滚动动画

### ✅ App Key Input（密钥输入框）

**位置**：页面中部 "Key Configuration" 区域

**测试方法**：

1. 在输入框输入任意字符
2. 观察字符是否显示为掩码 (`●●●`)
3. 点击右侧 "眼睛" 图标
4. 字符应变为明文显示
5. 尝试复制明文内容
6. 再次点击图标，字符恢复掩码

**测试点**：

- ✅ 默认掩码显示
- ✅ 显隐切换功能正常
- ✅ 明文状态下可复制
- ✅ 保存按钮状态逻辑（输入变更时变为 "Save"）
- ✅ 编辑中未保存时，操作仍使用旧 key（v0.6.1）
- ✅ 操作失败时显示 "Invalid App Key" 错误提示（v0.6.1）

## 🧩 交互测试

**测试所有按钮**：

## 🔧 调试技巧

### 查看组件状态

**使用 React DevTools**：

1. 打开 React DevTools
2. 切换到 "Components" 标签
3. 选择组件
4. 查看 props 和 state

### 查看网络请求

**使用浏览器开发者工具**：

1. 打开开发者工具（F12）
2. 切换到 "Network" 标签
3. 执行操作
4. 查看请求和响应

### 查看控制台日志

**查看日志输出**：

1. 打开开发者工具（F12）
2. 切换到 "Console" 标签
3. 查看日志、警告和错误
