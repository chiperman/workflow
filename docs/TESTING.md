# 组件测试指南

本文档说明如何测试项目中的所有组件。

---

## 🚀 快速开始

### 1. 启动开发服务器

```bash
npm run dev
```

访问：http://localhost:3000

---

## 🧪 组件测试清单

### ✅ TaskCard（任务卡片）

**位置**：主页面的两个卡片

**测试方法**：
1. 访问 http://localhost:3000
2. 观察两个任务卡片（Supabase 和 LeanCloud）
3. 点击 "Run Task" 按钮
4. 观察状态变化：
   - Loading 状态（按钮显示 "Running..."）
   - Success 状态（绿色提示）
   - Error 状态（红色提示）

**测试点**：
- ✅ 卡片布局和样式
- ✅ 按钮点击响应
- ✅ 加载状态显示
- ✅ 成功/失败消息
- ✅ 统计数字更新

---

### ✅ RollingNumber（滚动数字动画）

**位置**：TaskCard 中的统计数字

**测试方法**：
1. 点击 "Run Task" 按钮
2. 观察 "Auto" 和 "Manual" 数字的变化
3. 数字应该有滚动动画效果

**测试点**：
- ✅ 数字滚动动画
- ✅ 动画流畅度
- ✅ 数字更新正确

---

### ✅ SystemStatus（系统状态徽章）

**位置**：页面顶部（如果使用）

**测试方法**：
1. 观察页面加载时的状态
2. 状态应该从 "Checking" 变为 "Operational" 或 "Degraded"

**测试点**：
- ✅ 状态显示正确
- ✅ 颜色对应状态
- ✅ 状态自动更新

---

### ✅ Footer（页脚）

**位置**：页面底部

**测试方法**：
1. 滚动到页面底部
2. 查看版本号和链接

**测试点**：
- ✅ 版本号显示
- ✅ 链接可点击
- ✅ 样式正确

---

### ✅ CreateGuide（表创建引导）

**位置**：当表/类不存在时显示在 TaskCard 中

**测试方法**：

**方法 1：自然触发**
1. 如果 Supabase 表不存在，会自动显示
2. 点击 "Copy SQL" 按钮测试复制功能

**方法 2：模拟错误**
1. 临时修改环境变量使其无效
2. 点击 "Run Task" 触发错误
3. 观察创建引导是否显示

**测试点**：
- ✅ SQL 语句显示
- ✅ 复制按钮功能
- ✅ 提示信息清晰

---

### ✅ ErrorBoundary（错误边界）

**位置**：包裹整个应用

**测试方法**：

**现在已添加测试按钮！**

1. 访问 http://localhost:3000
2. 在页面右下角会看到一个红色按钮 "🧪 Trigger Error"
3. 点击按钮触发错误
4. 观察错误边界的 UI

**测试点**：
- ✅ 错误 UI 显示
- ✅ 错误消息清晰
- ✅ "Retry" 按钮功能
- ✅ "Go Home" 按钮功能
- ✅ 开发环境显示错误堆栈

**注意**：测试按钮只在开发环境显示（`NODE_ENV=development`）

## 🎨 视觉测试

### 响应式设计

**测试不同屏幕尺寸**：

1. **桌面**（> 1024px）
   - 打开浏览器开发者工具（F12）
   - 切换到响应式模式
   - 设置宽度为 1920px

2. **平板**（768px - 1024px）
   - 设置宽度为 768px
   - 观察布局变化

3. **手机**（< 768px）
   - 设置宽度为 375px
   - 观察移动端布局

**测试点**：
- ✅ 布局自适应
- ✅ 文字大小合适
- ✅ 按钮可点击
- ✅ 卡片堆叠正确

---

### 主题和样式

**测试点**：
- ✅ 米色背景（#fdfcf8）
- ✅ 衬线字体（标题）
- ✅ 无衬线字体（正文）
- ✅ 悬停效果
- ✅ 过渡动画

## 🧩 交互测试

### 按钮交互

**测试所有按钮**：

1. **Run Task 按钮**
   - 点击响应
   - Loading 状态
   - 禁用状态

2. **Copy SQL 按钮**（如果显示）
   - 点击复制
   - 成功提示

3. **Trigger Error 按钮**（开发环境）
   - 触发错误
   - 错误边界显示

4. **Retry 按钮**（错误 UI）
   - 重新加载页面

5. **Go Home 按钮**（错误 UI）
   - 返回首页

## 🔧 调试技巧

### 查看组件状态

**使用 React DevTools**：

1. 打开 React DevTools
2. 切换到 "Components" 标签
3. 选择组件
4. 查看 props 和 state

### 查看网络请求

**使用浏览器开发者工具**：

1. 打开开发者工具（F12）
2. 切换到 "Network" 标签
3. 执行操作
4. 查看请求和响应

### 查看控制台日志

**查看日志输出**：

1. 打开开发者工具（F12）
2. 切换到 "Console" 标签
3. 查看日志、警告和错误
